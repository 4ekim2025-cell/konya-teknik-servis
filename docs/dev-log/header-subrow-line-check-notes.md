# Header İkincil Çubuk Çizgisi Doğrulaması

Masaüstü görünümünde ikincil çubuğun üst çizgisi ayrı pseudo-element olarak çizildi. Çizgi, üst header’daki 1530 px içerik hesabıyla aynı sol ve sağ sınıra bağlıdır; logo alanının solundan ekran kenarına taşmaz.

390 piksel mobil görünümünde ikincil çubuk gizli olduğu için pseudo-element de kapalıdır. Mobil header yüksekliği ve logo yerleşimi etkilenmeden korunmuştur.
