# Mega Menü, Hero ve Takip Zemini Doğrulaması

Masaüstü ilk görünümünde hero yalnızca görsel katmanı ile görünür; `.hero` için ayrı düz renk arka plan yoktur. Koyu yeşil mega tetikleyici/mega menü override’ı kaldırıldı; temel bileşen yüzeyleri korunuyor.

390 piksel mobil görünümünde hero ve takip bölümü yatay taşma olmadan render edildi. Online Servis Takibi bölümü beyaz zeminde, diğer ana sayfa bölümleri mevcut kurumsal yüzey düzenini koruyacak şekilde görüntüleniyor.
