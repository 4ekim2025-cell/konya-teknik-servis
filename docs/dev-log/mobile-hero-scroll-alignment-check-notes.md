# Mobil Keşfet Hizalama Doğrulaması

390 px mobil tam sayfa görünümünde EŞLİ TEKNİK hero logosu merkezde yer alıyor. Keşfet bileşeninin metni, bordo dikey çizgisi ve aşağı yön oku; logo altında aynı merkez ekseninde görünür. Eski `translateX(-50%)` kuralı yalnızca serbest hero scroll konumu için geçerliydi ve kilitli logo bileşenindeki dönüşüm kaldırıldı.
